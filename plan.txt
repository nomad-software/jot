
This is a simple editor in the style of gEdit. When I mention another app, it is for reference and not to be perfectly copied, etc.

This is only for Linux at the minute.

Use latest version of qute for the UI. (https://github.com/nomad-software/qute)

Is there a way to use opengl for this similiar to Termite? Will this improve performance? I would like this editor to be as performant as possible but not at the cost of simplicity. This editor is to used for simple tasks, etc.

## Application

Create icon and linux application file similar to Termite and have it installed in the same way.
Create appimage workflow like Termite.

## Menu

Add appropriate keyboard shortcuts.

new window
new tab
save
save as
find
find and replace
settings
about
quit

## Toolbar

See Termite for an example.

New window (use similiar icon Termite uses)
new tab (use similiar icon Termite uses)
save
save as
find
settings

## Main window

No syntax highlighting
Simple text editor
line numbers if enabled
active line highlight if enabled

## Status bar (with drag handle)

Status (left aligned)
line/column (right aligned, characters or lines selected)
encoding (right aligned, utf8, etc.) Needs a right-click menu to change encoding.
line endings (right aligned, unix, etc.) Needs a right-click menu to change line endings.

## Settings

Add into appropriate tabs. See ApeMail or Termite for reference.

Show line numbers
Enable text wrapping
Highlight current line
Tab width in spaces
Uses spaces instead of tabs
font settings (font and size)
window themes (light, dark, follow system) (See Termite)
editor themes (light solarised, dark solarised, etc.) (See Termite)
keyboard shortcuts
Save settings to a file in ~/.config using Json.
